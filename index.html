WIRING UP YOUR GAMES

1 · THE FILES

Drop yourgame.html next to arcade.html in the repo root (or set CFG.folder). A shelf card requires both the game .html in the repo and a matching entry in info.json (or the baked-in GAMES list). Orphan HTML files never appear alone.

2 · METADATA (info.json)

Commit info.json next to arcade.html with a games array — one object per game (file, title, tagline, bio (HTML allowed), tags, thumb). Titles and bios support inline HTML/CSS (e.g. <h1 style="color:#ffd46b">…</h1>); scripts are stripped. JSON-only entries stay hidden until the .html exists; HTML-only files stay hidden until listed in JSON. Copy from info.template.json in the repo. Without a title, the shelf falls back to the game file’s <title> tag, then the filename.

2.5 · THUMBNAILS

In info.json, set thumb to any image URL or a full data:image/… string (use img_dataurl_converter_for_thumbnails.html to build one). Match each entry with "file": "yourgame.html". Empty or broken ⇒ neon initial plate from the display title.

3 · WHERE TO ACCESS

Push, enable Pages, then open …. On a private repo the API returns 404 — add a read-only token to CFG.token (MK-4t2kp6) or just fill CFG.manualFiles.

4 · OPERATOR COMMANDS (arcade.cmd)

Place arcade.cmd next to arcade.html. Lines run top to bottom on each load. Use StartUpAnnouncement("Message", "Title") for boot + banner + ticker, ScheduleAnnouncement("Later", "Title", 120) for timed toasts (seconds), Wait(2), Ticker("…"), Rescan(). # starts a comment. See ARCADE_CMD.md in the repo.

}
