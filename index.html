WIRING UP YOUR GAMES

1 · THE FILES

Drop yourgame.html next to arcade.html in the repo root (or set CFG.folder). Anything ending in .html appears automatically, except the exclusions in CFG.exclude — index.html is always skipped.

2 · METADATA (info.json)

Commit info.json next to arcade.html with a games array — one object per cartridge (file, title, tagline, tags, thumb). Copy from info.template.json in the repo. Without a title, the shelf falls back to the game file’s <title> tag, then the filename.

2.5 · THUMBNAILS

In info.json, set thumb to any image URL or a full data:image/… string (use img_dataurl_converter_for_thumbnails.html to build one). Match each entry with "file": "yourgame.html". Empty or broken ⇒ neon initial plate from the display title.

3 · WHERE TO ACCESS

Push, enable Pages, then open …. On a private repo the API returns 404 — add a read-only token to CFG.token (MK-4t2kp6) or just fill CFG.manualFiles.

{
  "version": 1,
  "games": [

      "hot": false
    }
  ]
}
